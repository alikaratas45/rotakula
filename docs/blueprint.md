# **App Name**: RotaKula

## Core Features:

- Thematic Routes Display: Display curated thematic routes specific to Kula, such as 'Geopark Discovery Route,' 'Historical Kula Houses Tour,' and 'Kula Flavor Tour'. Each route features a list of points of interest (POI) and a link to Google Maps for navigation.
- Kula-Specific POI Database: Maintain a database of points of interest (POI) unique to Kula, including descriptions, photos, and 'Show on Map' links.
- Route Saving: Allow users to save favorite thematic routes to a 'My Routes' page using the browser's localStorage.
- Featured Route of the Week: Show a 'Route of the Week' section on the main page, highlighting the 'Geopark Discovery Route' by default.
- Thematic Tour Cards: Show a number of cards on the home page, each featuring one of Kula's possible tours such as “Feel the historical Texture”, “Journey to the Heart of Nature”, “Flavors of Kula” etc.
- PWA Compatibility: Ensure the application functions as a Progressive Web App (PWA) for mobile-friendly access, including manifest.json and necessary PWA configurations.

## Style Guidelines:

- Primary color: Dark brown (#4E342E) to reflect the volcanic geopark structure of Kula.
- Background color: Beige (#F5F5DC), a desaturated version of the primary.
- Accent color: Turquoise (#40E0D0) to represent the rare plants among the lava rocks in the geopark, providing a vivid contrast.
- Headline font: 'Playfair' (serif) for headlines, providing an elegant feel; body font: 'PT Sans' (sans-serif) for body text.
- Use a full-page hero image on the homepage showcasing the Kula Fairy Chimneys or Historical Kula Houses.
- Maintain a modern, simple, and user-friendly design overall, making navigation intuitive.
- Incorporate custom icons related to Kula's attractions and local cuisine for visual appeal.
